# 2026 年 11 月这一轮改了什么

这一页只列**有前后数字**的改动。每条都能在 `docs/acceptance.md` 或对应用例里找到命令与原始输出；
没有实测的猜想不写进来。

---

## 1. 从「口播分镜表」到「按剧本剪」

以前只有一条路：手写分镜表 JSON。现在多了剧本产线——`index` 扫素材打标签，`story` 按台词排片。

| 项目 | 结果 |
|---|---|
| 示例《地铁追凶 第1集》 | 3 场 8 句 → 8 镜 / 12.90s，validate 0 错 0 警，成片体检 8 项 OK |
| 长剧本压测《长夜名单 第1集》 | 6 场 61 句 → **66 镜 / 2:37.67**，validate 0 错 0 警，qc 全过 |
| 素材复用 | 14 段素材撑 66 镜（平均 4.7 次/段，最多 7 次），相邻同源 **0** 次 |

修掉的 bug：长台词被拆成 2–3 镜时，字幕原先锚在**最后一镜**上，于是压到下一句头上——
实测重叠 **2.10s**、一次三条（屏幕上同时挂三行字）。现在锚在这句的第一镜、时长覆盖它占的全部镜头，重叠 0 处。

配套：`story` 报「素材复用最多几次」；`qc` 补了 `shot_rhythm`（见第 5 节）。

## 2. 快：切片缓存 + 多路并行 + 快编档

| 场景（8 镜 / 12.9s / 1080×1920） | 墙钟 |
|---|---|
| 串行、无缓存 | 9.44s |
| 4 路并行、无缓存 | 7.85s |
| 4 路并行 + 命中缓存 | **5.58s** |

切片按内容摘要命名（`_build/seg_<digest>.mp4`），改字幕、换配乐不会触发重切。
另外把「`--opt preview=true` 快编档」锁成**逐帧一致**：preview 与正式档都是 13.800s / 414 帧——
差一帧，叠加层 `enable='between(t,…)'` 的窗口就会错位。

## 3. 剪映草稿：从「只能写」到「能读回」

`cutwright import` 读真实草稿 `D:\Jianying\...\11月13日`（加密、48,896 字节）：

```
2 镜 / 9 条字幕 / 1 条音频 / 1280x720 / 18.03s（加密草稿）
```

读回的排布重建出成片，体检 8 项全 OK（`duration_match` 差 +0.000s）。

这一条线上修掉/补上的东西：

- **图片段不再丢**：草稿里 `type: "photo"` 的 PNG 原来被当「没画面」略过，时间线凭空短 3 秒；现在按静帧读回。
- **相对路径还原**：`##_draftpath_placeholder_<uuid>_##\textReading\…` 原来被当成相对当前目录，报出一串指向 `workspace\##_draftpath…` 的假错误。
- **字幕样式尽量像原来那样摆**：颜色 / 上下位置 / 有没有描边 / 关键词高亮从草稿里认出来；字号与描边粗细仍用画布默认（剪映 `font_size` 没有公开单位，猜 px 比不猜更糟）。
- **说清丢了多少**：`不还原: 转场 2 个、特效/滤镜 1 个、关键帧 2 个`——不再一句「不还原」糊过去。
- **长度 bug**：片段没写 `source_timerange` 时按素材全长算，2 秒的片段被当成 4 秒；现在优先用 `target_timerange`。

## 4. 声音：响度、让路、短配乐、无声片

| 项目 | 修前 | 修后 |
|---|---|---|
| 成片积分响度（66 镜那条） | RMS -19.6 dB / 峰值 -15.3 dB | **-13.8 LUFS** / 峰值 -11.9 dB |
| 配乐压台词（配乐比人声响 12 dB） | 与不压一样 | 整体低 **4.6 dB**（人声在时配乐自己退） |
| 5s 配乐铺 12s 片子 | 9–11s 整段无声 | **-20.1 dB**（循环铺满，接缝处可能有跳音） |
| 近乎无声的片子（-64.9 LUFS） | 被拉到 -14 LUFS（底噪放大 50 dB） | **跳过归一化**，仍 < -40 LUFS |

旋钮：`--opt loudness=-14`、`--opt duck=false`、`--opt duck_threshold=0.05`、`--opt duck_ratio=8`、`--opt music_loop=false`。

## 5. 质检：20 项 → 24 项

新增四项，都是「之后才可能出问题、但没人替你看」的东西：

| 检查 | 判什么 |
|---|---|
| `loudness_match` | 成片响度是否落在 -14 LUFS ±3 |
| `true_peak` | 真峰值是否超过 -1 dBTP |
| `text_readable` | 字幕是否太快读不完（上限 12 字/秒） |
| `shot_rhythm` | 同一场素材是否太少、镜长是否太齐/太长（`Q106`–`Q108`） |

语义约定：`error` 才让退出码变 1；`warn` 只提示。所以「字幕偏快」「素材重样」不会挡住出片，但会明说。

## 6. 文案与排版的小修

- **关键词换色**：`|` 与全角 `｜` 都认，成对交替（`自动裁剪｜变速｜补增益` → 白/黄/白）；分隔符不会再印在画面上。
- **1080 画布字幕溢出**：默认字幕从 145px 收到 72px（标定基准改回 2160×3840），并按画布宽度再折一次行。
- **中文避头尾**：`他说这话的时候，眼睛一直看着别处，像是在等谁` 按 8 字折行时，`，` 不再被扔到行首。
